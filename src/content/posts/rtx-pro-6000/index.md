## 環境構築でやったこと

### サーバーの管理に Ares を作った

Strata、vLLM、Ollama を切り替えて使うために、起動と停止を管理する小さなツールを作りました。設定でエンジンを選べて、どのエンジンでも OpenAI 互換の API で呼べるので、使う側のコードは変えずに済みます。

### メモリを使い切らないようにした

大きなモデルを載せると、メモリ不足で PC 全体が止まることがあります。そこで次のようにしました。

- 起動前に、空いているメモリが十分にあるかを確認し、足りなければ起動しない
- 推論プロセスが使えるメモリに上限を設ける
- CPU の優先度を下げて、ほかの作業が重くならないようにする
- メモリ保護で止まったときは自動で再起動しない。原因を確認してから手動で再開する

### 外には公開しない

API は自分の PC の中からだけ使えるようにしていて、外からはつながりません。
