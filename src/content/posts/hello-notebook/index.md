思ったことを、思ったときに書きとめる。そのためのノートをつくりました。

長い文章にまとめる必要はありません。数行のメモでもいいし、あとで書き足してもいい。大事なのは、考えたことを外に出しておくことです。

## 書き方

記事はすべて Markdown で書きます。新しい記事は、ターミナルで次のコマンドを打つだけで用意できます。

```bash
npm run new -- "記事のタイトル"
```

`src/content/posts/` の下にフォルダができるので、その中の `index.md` に本文を書きます。画像は同じフォルダに置いて、

```md
![代替テキスト](./photo.jpg "ここに書いた文がキャプションになります")
```

のように参照すれば、自動で最適化されて表示されます。

数式は `$...$`（文中）と `$$...$$`（独立した行）で書けます。たとえば $\sum_{k=1}^{n} k = \frac{n(n+1)}{2}$ のように。
