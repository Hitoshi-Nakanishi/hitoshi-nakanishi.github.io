ブログを始めました。日々考えたことや調べたことを、ここに書いていこうと思います。

最初の記事なので、このサイトの作りと記事の書き方を残しておきます。半分は自分用のメモです。

## 日本語と英語

記事は日本語と英語の両方で書けるようにしました。右上の「JA / EN」で切り替えられます。

同じ記事の日本語版と英語版は、同じフォルダに置いています。画像は両方で共有します。

```
src/content/posts/starting-notes/
  index.md         日本語
  index.en.md      英語
  unit-circle.svg  画像
```

日本語のページは `/` 以下に、英語のページは `/en/` 以下に出ます。英語版がない記事で EN を押すと、英語のトップページに移動します。記事一覧にはその言語で書いた記事だけが出るので、どちらか片方だけで書いても問題ありません。

新しい記事は次のコマンドで作れます。

```bash
npm run new -- "タイトル" my-slug        # 日本語
npm run new -- "Title" my-slug --en      # 同じ記事の英語版
```

## サイトの作り

サイトは [Astro](https://astro.build) で作った静的サイトで、GitHub Pages で公開しています。記事は Markdown のファイルで、`main` ブランチに push すると GitHub Actions がビルドして公開してくれます。CMS やデータベースは使っていません。

数式は KaTeX で、ビルドのときに HTML に変換しています。画像は記事と同じフォルダに置いておけば、ビルドのときにサイズが最適化されます。

本文のフォントは Noto Serif JP と EB Garamond にしました。ライトモードとダークモードを切り替えられます。アクセス解析や広告、コメント欄は付けていません。RSS は日本語が `/rss.xml`、英語が `/en/rss.xml` です。

## 書き方

### 数式

文中の数式は `$...$` で囲みます。たとえば $e^{i\theta} = \cos\theta + i\sin\theta$ のように書けます。

独立した行に書くときは `$$...$$` を使います。

$$
e^{i\pi} + 1 = 0
$$

複数行の式は `aligned` で揃えられます。

$$
\begin{aligned}
\cos x &= 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots \\
\sin x &= x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots
\end{aligned}
$$

### 画像

次のように書きます。`"..."` の部分はキャプションになります。

```md
![単位円](./unit-circle.svg "図1　単位円")
```

![単位円](./unit-circle.svg "図1　単位円")

### コード

コードはバッククォート 3 つで囲み、言語名を付けると色が付きます。

```python
import cmath
print(abs(cmath.exp(1j * cmath.pi) + 1))
```

### 表

| --- | --- | --- |
| $0$ | $1$ | $0$ |
| $\pi/2$ | $0$ | $1$ |
| $\pi$ | $-1$ | $0$ |

### 引用と脚注

引用は行頭に `>` を付けます。

> これは引用です。

脚注は本文に `[^1]` と書き、記事の最後に `[^1]: ...` で中身を書きます[^1]。
