## やりたいことと、作ったもの

### 調べた結果を、画面でも Jupyter でも同じように見たい

画面の Atlas と、API の Athena を作りました。計算はライブラリの側に置いて、Atlas も Jupyter も同じ Athena を呼ぶようにしています。こうすると、画面と Jupyter で同じ計算の結果を見られます。

### 市場をリアルタイムで見たい

市場をリアルタイムで監視する Titan と、Titan に株価を届ける Helios を作りました。

### 計算を速く回したい

バックテストや特徴量の計算のように重い部分は、Rust で書いています。特徴量の計算を同じ条件で測ったところ、Python で書いたものが 4.185 秒かかったのに対して、Rust では 0.0039 秒で、1,077 倍速くなりました。この時間にデータの読み込みは含んでいません。

### 同じ入力から、いつも同じ結果を出したい

最適化エンジンの Arts は関数型で書いています。計算の中心ではデータの読み書きをせず、同じ入力からはいつも同じ結果が出るようにしています。

### たくさんの Excel モデルを見比べたい

Mac で Excel のシートを読むのは大変です。1,000 以上の Excel シートを開こうとすると重くて開ききれず、シートをまたいで探すこともできません。

そこで Theia を作りました。Excel を開かずに、たくさんのワークブックから同じセルを抜き出して一覧にし、並べ替えたり絞り込んだりできます。見比べるワークブックは Metis で作っています。

### 手元の GPU で、PC を止めずに LLM を使いたい

大きなモデルを載せると、メモリ不足で PC 全体が止まることがあります。そこで、ローカル LLM サーバーの Ares を作りました。メモリを見ながら推論エンジンを起動・停止し、エンジンは Strata、vLLM、Ollama から選べます。どれも OpenAI 互換の API で呼べるので、エンジンを変えても使う側のコードは同じです。

### 会議の記録を、外に出さずに残したい

会議や通話の音声を外のサービスに送らずに、手元で文字起こしして議事録にするために、Lethe を作りました。

### 公開してはいけないものを、うっかり出さない

このブログはリポジトリごと公開しているので、下書きもコミットの履歴も誰でも読めます。そこで、コミットや push の前に自動で確かめる Argus を作りました。

### 作ったレポートを、コードと分けて残したい

レポートは LaTeX と PDF で、コードとは別の qrxreports というリポジトリに置いています。

## 公開しているもの、公開する予定のもの

単独で使えるものは、qrxarts とは別のリポジトリにしていて、順に公開しています。

| 名前 | 何をするか | 状態 |
| --- | --- | --- |
| [Lethe](https://github.com/Hitoshi-Nakanishi/lethe-app) | 会議や通話を Whisper で文字起こしして、議事録にするデスクトップアプリ | 公開 |
| Theia | Excel のバリュエーションモデルを、Excel を開かずに見比べるデスクトップアプリ | 公開予定 |
| Ares | 手元の GPU で動かすローカル LLM サーバー | 公開予定 |

QRX とは別に、このブログも公開しています。
